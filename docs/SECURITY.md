# Public/private data separation

**Public:** primary program URLs, timestamps, SHA-256 source fingerprints, source-supported program details and generic evidence summaries.

**Private:** applicant accounts, identity/contacts, API tokens, cookies, grant application contents, acceptance/denial tied to an individual, balances and proprietary predictions/outcomes. Never place these in this public Git history, CI artifacts or PRs.

A bot PR is a suggestion—not approval to merge, change hosting, claim grants, use paid services or read private accounts. Inspect all proposed source data for prompt injection, accidental secrets and personal details. Do not store complete copyrighted source pages; keep links, hashes and concise summarized facts.
