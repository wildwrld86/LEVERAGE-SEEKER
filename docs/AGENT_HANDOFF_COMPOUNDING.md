# Creeper / research-agent handoff — compounding mode

Read `AGENTS.md`, `docs/COMPOUNDING_PROTOCOL.md`, `data/daily/README.md`, and `docs/SECURITY.md`.

Mission: Keep a **small, truthful, useful** opportunity-intelligence time series that can later serve users. Use research branch `research/intelligence-ledger` for public data proposals. Do not change main or auto-merge. Coordinate agent tasks in the private `grokbot-desk` when access exists; no repeated work or self-assigned expensive tasks.

Research priority:
1. Directly useful $0/low-CapEx access, substantive price/eligibility changes, genuinely open/closed grants/credits, and verified buyer problems.
2. Important expiry, dead opportunities, inaccurate third-party listings, and unverified claims.
3. Opportunities with recurring relevance for other solo founders.
4. SECONDS MATTER customer pain, consent/registration, low-cost delivery paths and distribution; don't assume accounts or customers.

For each material discovery, append no more than five public observations to a new date-named JSON file using the documented schema; validate and rebuild the feed when tooling exists. Write a branch commit only if permitted. Every claimed persisted item must link to a GitHub commit. Never assert a bot wrote to the repo merely because it generated a report.

Weekly: report verified tracked subjects, changes, closures, rejected false positives, and usefulness insights. If no new delta, be brief. Require user approval for merge/deploy; do not contact anyone, spend money, or handle private customer/account data.
